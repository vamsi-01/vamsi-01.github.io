# Vamsi Mathala — Vamsi Mathala Portfolio

A static portfolio built with HTML, CSS and vanilla JavaScript. No npm dependencies or build step are required.

## Run locally on macOS

```bash
cd vamsi-vamsi-mathala-portfolio
python3 -m http.server 4173
```

Open http://localhost:4173 in your browser.

You can also open `index.html` directly, although using the local server is recommended.

## Deploy

Upload this folder to any static host such as Netlify, Vercel, GitHub Pages or an ordinary web server. No build command is required.

## Motion and accessibility

- Scroll-triggered staggered reveals for sections and cards
- Pointer-responsive 3D card tilt and spotlight on fine-pointer devices
- Magnetic buttons and brand mark
- Smooth card spring-back and interactive technology filters
- Reduced-motion and touch-device fallbacks

The hero vehicle is rendered from the local `assets/garage-car-concept.webp` image; it is not a live 3D model.
